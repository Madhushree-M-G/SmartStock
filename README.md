# SmartStock

SmartStock is a lightweight and user-friendly inventory management system designed for small and medium-sized retail businesses. It helps manage product stock efficiently through a simple interface with categorized image-based product listings.

## 🚀 Project Overview

SmartStock was developed to address the inventory tracking needs of **Varcons** and her vendors, who required a minimal, intuitive system that could operate without extensive technical knowledge or internet dependency.

## ✨ Features

- 📦 Add and manage products with images
- 🗂️ Categorize items (e.g., Dresses, Accessories)
- 🔍 Search and browse product inventory easily
- 💾 Local storage using SQLite database (`inventory.db`)
- 📸 Visual identification through product images

## 🛠️ Tech Stack

- **Python** (Flask or Tkinter, depending on interface used)
- **SQLite** for lightweight database management
- **PIL / OS modules** for image handling
- **File-based architecture** with categorized image folders

## 💡 How It Meets Vendor Requirements

The application:
- Enables **quick product addition** with category and image
- Supports **visual navigation** for vendors unfamiliar with complex UIs
- Runs **offline**, suitable for stores without consistent internet
- Uses **simple architecture** for easy maintenance

## 🔧 Setup Instructions

1. Clone or unzip the project:
  git clone <repo-url>
  
2. Navigate to the project folder:
  cd SmartStock

4. Run the application:
  python app.py
